## 🌟 Overview

MovieHub is a comprehensive web application that allows users to explore the latest trending and popular movies, TV shows, and celebrities. Powered by the TMDB API, it provides rich details including trailers, cast information, recommendations, and more—all within a sleek, modern, and responsive interface.

## 🚀 Features

- **Dynamic News Feed**: Real-time trending and popular content across movies and TV shows.
- **Deep Discovery**: Detailed pages for every title, featuring synopses, ratings, and production details.
- **Trailer Integration**: Seamlessly watch trailers from YouTube and Vimeo directly within the app.
- **Search & Filter**: Powerful search functionality to find exactly what you're looking for.
- **Cast & Crew**: Explore the filmography of your favorite actors and directors.
- **Personalized Recommendations**: Discover similar content based on what you're currently viewing.
- **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

- **Frontend**: React (v18+)
- **Build Tool**: Vite
- **State Management**: Redux Toolkit
- **Routing**: React Router DOM (v6+)
- **API Communication**: Axios
- **Styling**: Tailwind CSS
- **Icons**: Remix Icon
- **Video Playback**: React Player

## 📦 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/arshad-khan1/moviehub-react-project.git
   cd moviehub-react-project
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Environment Variables**:
   Create a `.env` file in the root directory and add your TMDB API key:
   ```env
   VITE_TMDB_API_KEY=your_api_key_here
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

5. **Build for production**:
   ```bash
   npm run build
   ```
